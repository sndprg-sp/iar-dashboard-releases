IAR Dashboard

Read your school’s IAR assessment data — on your own computer.

Download for Mac Apple silicon · macOS 12 or later Download for Windows Windows 10 or later

 

Your data never leaves this computer. Student files you load are read and stored only on your own machine. Nothing is uploaded, and there is no account to create.

Installing on Windows

Windows may warn that the publisher is unknown. Choose More info → Run anyway. We’re working on removing that warning.

Updates

The app updates itself. Once it’s installed you won’t need this page again — it’ll offer new versions as they’re released.
